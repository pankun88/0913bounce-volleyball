경기장 송출 설정

관객 대시보드 열기 수동 관람 화면 열기

상단과 이 설정의 관객 대시보드 열기 버튼은 같은 주소에서 저장된 자동 교대·고정 설정을 사용합니다. 15초는 부문 교대 간격이며 송출 지연이 아닙니다. 전환 타이머는 화면마다 독립적으로 동작합니다. 화면마다 남녀부를 각각 선택하려면 수동 관람 화면 열기를 사용해 각 화면에서 부문을 선택하세요.

데이터 백업 / 복원

v3 백업에는 대진·코트 대기열·워크플로 manifest가 포함됩니다. 복원은 서버 manifest 검증 후 적용합니다.

초기 백업에는 남녀 부문 정보가 없으므로 자동 판별이 어려울 때만 직접 선택하세요.

복원하면 현재 입력된 데이터가 백업 파일 내용으로 전부 대체됩니다.

대회 전체 초기화

남자부·여자부, 팀, 대진·결과, 코트, 기록관/워크플로 데이터, 접근 코드, 송출·대회 설정을 모두 초기화합니다. 관리자 로그인 권한은 유지됩니다.

기록관 접근 코드

접근 코드는 생성·재발급 때만 표시됩니다. 코드로 받은 권한은 계정 단위이며 12시간 후 만료됩니다. 재발급·전체 폐기는 모든 기록관의 기존 권한을 무효화하지만, 입력 중인 초안과 잠금은 유지됩니다.


      

        운영 안내
        
    
          
  • 기기 분실·계정 문제: 해당 계정만 아래 목록에서 폐기한 뒤 새 코드로 다시 권한을 받게 하세요. 다른 기록관의 권한은 유지됩니다.
    • 
          
  • 코드가 넓게 유출됨: 접근 코드를 재발급하거나 폐기해 모든 기존 권한을 무효화하세요. 입력 중인 경기는 아래 검수 목록의 잠금 강제 해제로 별도로 처리하며, 코드 작업이 잠금을 자동 해제하지 않습니다.
